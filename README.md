# RTS 策略游戏 Demo

基于 Unity 开发的轻量级 RTS（即时战略）游戏 Demo。

## 核心功能
- **建筑系统**：基于面向对象设计（继承与多态），实现基地、兵营、防御塔等不同建筑的逻辑扩展与占领机制。
- **A* 寻路**：手写基于网格的 A* 寻路算法，支持八方向移动、代价计算及斜向穿墙防卡死检测。
- **单位调度**：实现兵源选择、派兵、驻军战斗与占领结算的完整闭环。
- **比赛阶段**：实现普通阶段与 Fever 阶段的倒计时切换，以及资源管理与升级系统。
- **RTS 操作**：实现鼠标框选、右键拖动视角、滚轮缩放等经典 RTS 相机操作。

## 技术栈
Unity、C#、A* 寻路算法、面向对象架构、UGUI
